# אבן דרך 1 — מסירה לבדיקה

תאריך: 5 באוקטובר 2026. סטטוס: המימוש והבדיקות הושלמו; ממתין לבדיקה ולאישור המפתח.

## מה נמסר

משחק פעיל עם בחירת Easy/Medium/Hard, ברירת מחדל Medium, התחלה כ־X מול O, יריב Minimax מקומי עם טעויות לפי רמה, וכל תוצאות המשחק. מוצגים תור, קושי וסימני השחקנים; ניצחון מסומן בקו סטטי. קלט לא חוקי או כפול נחסם והלוח נעול לאחר סיום.

העיצוב כולל דשא, מסגרת עץ, לוח גיר, גופן Nunito Sans מקומי, רכיבים נגישים ופריסה לאורך ולרוחב. שגיאת יריב מאפשרת Restart באותו מסך; שגיאת רינדור מאפשרת התחלת הפעלה חדשה.

הגרסה כוללת את אבן הדרך הראשונה בלבד. אין מונים, משחק חוזר רגיל, הגדרות משוב, אודיו, אנימציות משוב, offline, התקנה או פרסום. לאחר משחק תקין שהסתיים, רענן את הדף כדי להתחיל משחק נוסף.

## הרצה ובדיקה שלך

פתח את [המשחק המקומי](http://127.0.0.1:4173), בחר רמת קושי ולחץ Start Game. בדוק הקשה על תאים, המתנה לתור המחשב והצגת התוצאה. נסה את הרמות הנוספות אחרי רענון, וכן חלון צר או אופקי וניווט באמצעות מקלדת.

אם התצוגה המקדימה הופסקה, הרץ בשורש הפרויקט `npm run preview`. הוראות הקמה ובדיקות נוספות ב־[README](../README.md).

## תנאי סיום וראיות

- [x] **בחירת קושי ומשחק שלם:** בדיקות דפדפן עברו לכל שלוש הרמות. נבדקו לוח ריק, התחלה אנושית והשלמת משחק. שלוש התוצאות נבדקו דרך מהלכי משחק רגילים עם אקראיות נשלטת בבדיקות בלבד.
- [x] **חוקים:** 16 בדיקות קווי ניצחון מכסות את שמונת הקווים לשני הסימנים, בנוסף לתיקו ולניצחון בלוח מלא. כל 5,478 הלוחות הנגישים במשחק חוקי נבדקו מול בודק תוצאה עצמאי.
- [x] **קלט ותורות:** בדיקות reducer ודפדפן מכסות אינדקסים לא תקינים, תא תפוס, קלט כפול ומהיר, תור מחשב וסיום; לא נוצר מהלך נוסף ולא משתנה לוח סופי.
- [x] **קושי ויכולת לנצח:** כל מצבי תור המחשב החוקיים נבדקו מול Minimax עצמאי המעריך תוצאות. בכל רמה הוכחו בחירות אסטרטגיות, טעויות גרועות ממש כאשר קיימות, וחזרה לבחירה טובה כשאין טעות אפשרית. נבדקו ספי 0.50/0.25/0.10 ומסלול ניצחון מול Hard.
- [x] **תזמון וחיי רכיב:** בדיקות fake timers עם StrictMode מכסות טיימר יחיד, השהיה של 400ms, ניקוי ב־unmount, נראות ורקע/חזרה, pagehide/pageshow, שגיאה והתאוששות. פעולות מדור משחק ישן או מספר מהלך לא תואם נדחות. גם פלט יריב בלתי חוקי מוביל להתאוששות בלי לפגוע בלוח.
- [x] **ממשק ונגישות:** בדיקות מקלדת, focus, מגע מדומה, תוויות, גודל תאים וכפתורים ולוח ריבועי עברו. נבדקו 390×844, 320×568, 844×390 ו־1280×800, ללא גלילה אופקית. גלילה אנכית מאפשרת גישה לתוכן בחלון אופקי נמוך. נבדקו גם גופן חסום ותנועה מופחתת. יחס צבעי הטקסט ירוק/קרם הוא 10.00:1; סימני X/O מול הלוח הם 8.08:1 ו־5.22:1 בהתאמה. צילומי המסך נבדקו חזותית.
- [x] **build וראיות:** בדיקת טיפוסים ובניית production עברו, 37 בדיקות Vitest ו־15 בדיקות Playwright עברו. קיימים ששת צילומי החובה, צילום התאוששות וצילומי פריסות.

סביבת הבדיקות: Windows, Node.js 24.15.0, npm 11.12.1, Google Chrome 154.0.8037.95. הגרסה נבנתה מתלויות נעולות ב־package-lock.json. סבב האימות האחרון הריץ `npm test`, `npm run build`, `npm run test:e2e` בהצלחה.

בדיקת רשת של משחק שלם הראתה בקשות לנכסים מקומיים בלבד וללא שגיאות דפדפן. localStorage ו־sessionStorage נותרו ריקים, לא נכתבו cookies ולא נרשם Service Worker. קוד האפליקציה אינו כולל ממשקי אחסון שחקן או בקשות רשת למשחק.

## מגבלות ושער אישור

בדיקות הדפדפן והמגע בוצעו ב־Chrome ובאמולציה. טרם בוצעו בדיקות על מכשירי Android/iOS אמיתיים או בדיקת שימושיות עם ילדים; אלה נכללות באימות השחרור המאוחר יותר. טקסטורות ה־SVG הן נכסים מקוריים מקומיים המיישמים את השפה החזותית, ולא צילומים זהים לגיליונות הייחוס.

אבן הדרך הראשונה מוכנה לבדיקה. לא הוחל במימוש אבן הדרך השנייה. בהתאם ל־[מסמך אבני הדרך](MILESTONES,md.md), המשך פיתוח לאבן הדרך הבאה דורש אישור מפורש מהמפתח לאחר הביקורת.
