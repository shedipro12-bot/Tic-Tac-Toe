# מסירת אבן דרך 4 — משחק ללא חיבור והתקנה

סטטוס: המימוש הושלם ונמסר לבדיקה ב־5 באוקטובר 2026. אישור המפתח עדיין ממתין.

## מה זמין לבדיקה

תצוגת production מקומית: [פתח את המשחק](http://127.0.0.1:4173/).

1. פתח מקוון והמתן להודעה **Ready to play offline**.
2. שחק, בחר קושי ופתח Settings. נתק חיבור ובדוק שמשחק חי ממשיך מאותו מצב.
3. סגור ופתח את האפליקציה מחדש ללא רשת. מופיע Setup עם Medium ושני מתגי המשוב On; המונים מתחילים באפס.
4. שחק בכל רמת קושי, צבור תוצאות והשתמש ב־Play Again וב־Restart בזמן תור מחשב. בדוק Settings, צלילים ואנימציות ללא רשת.
5. בדפדפן תומך השתמש באפשרות ההתקנה המובנית ופתח בחלון עצמאי. התקנה אינה דרישה למשחק. בתצוגה מקומית צריך לשמור את השרת פעיל לטעינה הראשונה; לאחר שמירה מלאה המשחק נשען על המטמון.

ביקור ראשון ללא מטמון אינו יכול להוריד משחק ללא רשת. אם המעטפת שמורה אך קוד המשחק חסר, מופיעה **Connection needed** עם **Connect to the internet to load the game.**. כשהרשת חוזרת המשאבים נבדקים והמשחק נפתח ב־Setup ללא כפתור Retry. אם גם המעטפת או סקריפט האתחול חסרים, ייתכן מסך שגיאה של הדפדפן.

## המימוש

- נוסף manifest באנגלית ו־LTR עם מזהה, scope ו־start URL בשורש, standalone וללא נעילת orientation. נוספו ארבעה PNG מקוריים: 192, 512, maskable בגודל 512 ו־Apple בגודל 180; הסימנים נמצאים באזור הבטוח של האייקון המחופה.
- vite-plugin-pwa ‏2.0.0 עם Workbox generateSW, רישום חיצוני יחיד והכנה ברקע. worker פיתוח כבוי. עדכון רגיל ממתין ואינו מרענן משחק חי.
- precache כולל את כל HTML/JS/CSS, manifest, מידע האתחול, שמונת קובצי הגופן, שלוש הטקסטורות, ארבעת הצלילים וארבעת האייקונים. קובץ עזר ייחודי לגרסה מבצע בדיקת מלאי, תיקון מבוקר וטווחי MP3. אין runtime cache כללי.
- מוכנות דורשת worker פעיל, מזהה build תואם וכל משאב נדרש במטמון. כשל רישום, הורדה, מכסה או גישה למטמון משאיר משחק שמיש פעיל ומסיר את הכרזת המוכנות. ניסיון חוזר מתבצע בחזרת חיבור או נראות, ללא לולאת רקע.
- bootstrap קטן מציג הודעת חיבור גם כשה־React והקוד של המשחק אינם זמינים. הוא מרענן רק מסמך שלא הצליח לטעון משחק, לאחר בדיקת זמינות הליבה. ניתוק של משחק שכבר נטען אינו מאפס אותו.
- המטמון מכיל נכסים בלבד. מצב משחק, קושי, מונים והעדפות נשארים בזיכרון; worker אינו מקבל פעולות משחק. מטמון זר באותו origin נשמר בבדיקת התיקון.
- ה־build נכשל אם נכס דרוש אינו מופיע במלאי, חורג ממגבלת 2 MiB או אינו תואם ל־SHA-256. נבדקים גם manifest, PNG וקישורים לסקריפטים חיצוניים.

## תוצאות האימות

סביבה: Windows, Node ‏24.15.0, npm ‏11.12.1, Chrome ‏154.0.8037.95, Playwright ‏1.63.0. הבדיקות מול production ב־127.0.0.1:4173, הקשר מקומי מאובטח המתאים ל־Service Worker.

- `npm test`: **59/59** בדיקות יחידה עברו.
- `npm run typecheck`: עבר.
- `npm run build`: עבר, כולל בדיקת מלאי, גודל ושלמות משאבים.
- `npm run test:e2e`: **69/69** בדיקות דפדפן עברו. לאחר הרחבת בדיקת המטמון לחסימת Cache API, גם אותה בדיקה הורצה בנפרד ועברה.
- **12/12 = 100%** ממקרי קבלת המשחק offline שנקבעו לפני הרצתם עברו. המכנה קבוע; התקנה ומקרי כשל נבדקים בנוסף ואינם מחליפים מקרה קבלה.

רשימת 12 מקרי הקבלה ב־`tests/e2e/pwa.spec.ts`:

1. מסמך חדש offline: משחק מלא ב־Easy.
2. מסמך חדש offline: משחק מלא ב־Medium.
3. מסמך חדש offline: משחק מלא ב־Hard.
4. ניצחון, הפסד, תיקו, מונים מצטברים, קושי הבא, replay, ביטול מהלך ישן ב־restart וטאבים עצמאיים.
5. Settings ללא רשת: Sound On, Animations On.
6. Settings ללא רשת: Sound On, Animations Off.
7. Settings ללא רשת: Sound Off, Animations On.
8. Settings ללא רשת: Sound Off, Animations Off. ארבעת המקרים כוללים תור מחשב, תוצאה, reduced motion ופריסה צרה/רחבה.
9. כל 28 המשאבים זמינים offline; גופן וטקסטורות, פענוח ארבעת הצלילים, השמעת HTMLAudioElement אמיתית לאחר מחווה וטווחים תקינים/לא תקינים. נכסים או API חסרים אינם מקבלים HTML מה־worker.
10. ניתוק במסמך חי שומר מצב; רענון offline מאפס משחק והעדפות.
11. סגירת תהליך Chrome והפעלתו מחדש עם profile שמור: מסמך offline מגיע מ־Service Worker כש־HTTP cache כבוי.
12. אירוע persisted pageshow במסמך offline מאפס הפעלה. זו הזרקת אירוע; בנוסף נשמרה בדיקת bfcache אמיתית מקוונת המאמתת זהות מסמך ואירוע persisted.

בפתיחת המסמכים החדשים נכבתה גישת רשת ו־HTTP cache נוטרל; תגובות למשאבי המשחק נבדקו כמגיעות מ־Service Worker. הצלחה אינה מבוססת רק על קוד שנותר בזיכרון.

מקרי הכשל הנוספים עברו: ביקור ראשון offline ללא מטמון; חסימת רישום והתאוששות; חסימת הורדת MP3 בבקשה ששייכת ל־worker בעת precache; מחיקת קוד ליבה והחלמה לאחר חיבור; מחיקת גופנים וצלילים; הזרקת QuotaExceededError עם אימות 12 כתיבות שנכשלו; חסימת CacheStorage.open; וסביבה ללא תמיכת worker. לא הופיעה מוכנות מטעה, ומשחק שהליבה שלו זמינה נותר תקין. בדיקות fallback הקודמות מבודדות מ־workers; בדיקת אנימציה ממתינה לרינדור בפועל.

## התקנה וראיות

התקנה אמיתית ב־Chrome במחשב עברה ב־`tests/e2e/installation.spec.ts`: פרופיל בדיקה מבודד, `PWA.install`, שינוי העדפת הפעלה לחלון עצמאי, ואז `PWA.launch`. נבדק `display-mode: standalone` של חלון האפליקציה המותקנת, ללא אמולציה של display-mode. אחרי ניתוק ורענון עם HTTP cache כבוי המסמך הגיע מ־worker, הושלם משחק Medium ונבדקו פריסות 390×844 ו־844×390. התקנת הבדיקה הוסרה ב־finally.

## מגבלות והמשך

התקנה במחשב אומתה. מכשירי Android/iOS אמיתיים, Safari/גרסה ראשית קודמת, בדיקת שימושיות, HTTPS ציבורי, Cloudflare, כותרות HTTP וזרימת עדכון בין טאבים טרם נבדקו או מומשו במסגרת זו; הם שייכים לאבן דרך 5. פריסה נבדקה במידות חלון שונות, ללא הבטחה להתנהגות מכשיר פיזי.

שמירת מטמון תלויה בדפדפן: המשתמש או מערכת ההפעלה יכולים למחוק אותו. בכל פתיחה וחזרה לנראות נבדקת מוכנות מחדש. המשחק אינו מבטיח פתיחה כשמעטפת האתחול עצמה חסרה.

לאחר הבדיקה נדרש אישור המפתח. אבן דרך 5 והעלאה ל־GitHub ממתינות להוראה מפורשת.
